# astrbot_plugin_blockly

> Blockly 可视化编程 —— 让 AstrBot 在线编程、操控 AstrBot。

使用 [Blockly](https://blockly.com) 积木（或直接编写 Python）创建"程序"，当机器人收到消息时执行。
**传出消息还是返回消息由积木决定**：

- **返回消息**（`返回消息` 积木）：回复内容并劫持事件，不让 AstrBot 继续处理。
- **传出消息**（`传出消息` 积木）：放行消息，交给 AstrBot 继续处理（如调用 LLM 回复）。

## 特性

- 多程序（多文件）管理：新建、复制、删除、导入、导出、开启/关闭、优先级排序。
- 独立 WebUI（AstrBot 插件 Pages）：Blockly 积木模式 / Python 代码模式，**新建时选定**，两者相互隔离、不可中途切换。
- 积木自动生成 Python 代码，后端在受限沙箱中执行（白名单 builtins + AST 静态检查 + 超时）。
- AstrBot 专属积木：返回消息 / 回复 / 传出消息 / 停止事件、主动发送、调用 AI、HTTP 请求、日志、延时等。
- 「回复 / 返回消息 / 主动发送」积木支持消息类型选择：**文本 / 图片 / 语音**（图片语音填 URL 或本地路径）。
- **「持久化数据」积木**：全局变量跨程序共享、重启不重置（JSON 落盘），`设置 / 获取 / 删除`。
- **「全局函数」积木**：定义一次、任意程序调用，支持参数与返回值。
- **「类型转换 / 类型判断 / JSON 处理 / 文本分割 / 消息属性判断」积木**：字符串↔数字转换、JSON 解析/序列化/取值、按分隔符分割文本、变量与消息类型判断。
- 多种事件入口：收到消息 / 撤回消息 / 新成员加入 / 群成员退群 / 戳一戳。
- 每个程序可配置触发条件：全部消息 / 包含关键词 / 前缀 / 正则 / 仅管理员。
- 新建程序时自动避免同名。
- 可对「AI 回答」积木授权一个或多个可用模型（**提供商 ID + 模型 ID** 白名单）。
- WebUI 一键"测试运行"：用模拟消息验证程序行为，无需真实发消息。
- 工具箱积木搜索：工具栏搜索框按关键词实时筛选积木。
- 主题设置：多主题管理（zip 导入/导出、文件树编辑、删除确认），默认 / 深色 / 自定义主题切换，切换后刷新页面生效。
- 前端离线可用：Blockly 库已内置在插件内。

## 安装

把 `astrbot_plugin_blockly` 目录放入 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理中启用/重载插件。

## 使用

### WebUI（推荐）

插件启用后，在插件详情页打开 **Blockly 可视化编程** 页面：

1. 点击"新建"，填写名称并选择编辑方式（积木模式 / 代码模式，选定后不可切换）。
2. 在对应编辑器中编写逻辑（积木拖拽，或直接写 Python）。
3. 配置名称、触发条件、优先级、超时、"可用模型"白名单等。
4. 点击"测试运行"验证，点击"保存"生效。
5. 在左侧列表开启程序开关。

### 聊天指令（管理员）

| 指令 | 说明 |
| --- | --- |
| `/blockly` | 帮助 |
| `/blockly list` | 列出所有程序 |

| `/blockly delete <id>` | 删除程序 |
| `/blockly reload` | 从磁盘重新加载程序 |

## 积木说明（AstrBot 专属）

- **事件**：`当接收到消息`（程序入口）、`当撤回消息`、`当新成员加入`、`当群成员退群`、`当被戳一戳`
- **消息**：消息文本 / 发送者名称 / 发送者ID / 群ID / 会话 / 平台 / 是否管理员 / 是否私聊 / 消息类型判断（纯文本/图片/表情/@/语音/引用）
- **回复与发送**：
  - `返回消息`（回复并劫持事件，AstrBot 不再处理）
  - `回复`（发送但不劫持，其他匹配程序仍会执行）
  - `传出消息`（放行给 AstrBot 继续处理）
  - `停止事件` / `主动发送`
  - 上述 `返回消息` / `回复` / `主动发送` 均可选择消息类型：**文本 / 图片 / 语音**（图片语音填 URL 或本地文件路径）
- **AI**：`AI 回答`（按程序「可用模型」白名单——**提供商 ID:模型 ID**，如 `openai:gpt-4o`——调用模型；当前会话模型不在白名单时自动切换）
- **网络 HTTP**：`HTTP GET`、`HTTP POST`（JSON）
- **持久化**：`持久化变量设置 / 获取 / 删除`——全局变量跨程序共享、重启不重置
- **全局函数**：`全局函数定义`（齿轮编辑参数名，函数体可含 `全局函数返回`）、`调用全局函数`（齿轮设置参数，按顺序传值）。定义块所在程序保存并运行一次后即可被任意程序调用
- **类型转换**：`类型转换`（字符串/整数/浮点数/布尔/列表——列表按 JSON 数组/换行/逗号智能解析）、`类型判断`（返回变量类型名称）
- **JSON**：`JSON 解析`（字符串→对象）、`JSON 序列化`（对象→字符串，保留中文）、`取 JSON 的键`（可传 JSON 字符串，支持默认值）、`JSON 所有键`（返回键列表）
- **文本**：`按分隔符分割`（默认 `,`，输出列表）
- **其他**：日志 / 延时 / 停止事件

标准积木：逻辑、循环、数学、文本、列表、变量、函数 全部可用。

## 安全说明

- 程序在**受限沙箱**中执行：仅暴露白名单 builtins（不含 `__import__`、`open`、`eval`、`exec` 等），并提供 `event`/`ctx`/`_blk` 三个对象；执行前还会通过 **AST 静态检查**阻断 `import`、魔术属性（`__class__` 等）与类定义等常见逃逸路径。
- 每个程序有独立的**执行超时**（默认 30 秒），超时自动终止。
- 注意：`while True` 等 CPU 密集死循环无法被 asyncio 超时中断，请在程序中避免；使用积木"延时/循环"时注意次数。
- 请只允许可信人员使用本插件（程序拥有与机器人同等的操作能力，如发送消息、调用 AI、发起 HTTP 请求）。
