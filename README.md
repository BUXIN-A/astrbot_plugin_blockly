# astrbot_plugin_blocky

> Blocky 可视化编程 —— 让 AstrBot 在线编程、操控 AstrBot。

使用 [Blockly](https://blockly.com) 积木（或直接编写 Python）创建"程序"，当机器人收到消息时执行：

- **返回消息**：劫持消息，不让 AstrBot 处理，直接把内容回复给用户。
- **传出消息**：在本插件处理完消息后，正常传递给 AstrBot 继续处理（如调用 LLM 回复）。

## 特性

- 多程序（多文件）管理：新建、复制、删除、导入、导出、开启/关闭、优先级排序。
- 独立 WebUI（AstrBot 插件 Pages）：Blockly 积木模式 + Python 代码模式双编辑。
- 积木自动生成 Python 代码，后端在受限沙箱中执行（白名单 builtins + 超时）。
- AstrBot 专属积木：回复/返回消息、传出消息、主动发送、调用 AI、HTTP 请求、日志、延时等。
- 每个程序可配置触发条件：全部消息 / 包含关键词 / 前缀 / 正则 / 仅管理员。
- WebUI 一键"测试运行"：用模拟消息验证程序行为，无需真实发消息。
- 前端离线可用：Blockly 库已内置在插件内（约 1.5MB）。

## 安装

把 `astrbot_plugin_blocky` 目录放入 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理中启用/重载插件。

## 使用

### WebUI（推荐）

插件启用后，在插件详情页打开 **Blocky 可视化编程** 页面：

1. 点击"新建"，选择模式（传出消息 / 返回消息），默认生成对应积木。
2. 拖拽积木编辑逻辑，或切换到"代码模式"直接写 Python。
3. 配置名称、触发条件、优先级、超时等。
4. 点击"测试运行"验证，点击"保存"生效。
5. 在左侧列表开启程序开关。

### 聊天指令（管理员）

| 指令 | 说明 |
| --- | --- |
| `/blocky` | 帮助 |
| `/blocky list` | 列出所有程序 |
| `/blocky on <id>` | 开启程序 |
| `/blocky off <id>` | 关闭程序 |
| `/blocky new <名称>` | 新建程序 |
| `/blocky delete <id>` | 删除程序 |
| `/blocky reload` | 从磁盘重新加载程序 |

## 积木说明（AstrBot 专属）

- **事件**：`当接收到消息`（程序入口）
- **消息**：消息文本 / 发送者名称 / 发送者ID / 群ID / 会话 / 平台 / 是否管理员 / 是否私聊
- **回复与发送**：`回复`（发送并继续）、`返回消息`（发送并劫持）、`传出消息`（放行给 AstrBot）、`主动发送`
- **AI**：`AI 回答`（调用当前会话的模型）
- **网络 HTTP**：`HTTP GET`、`HTTP POST`（JSON）
- **其他**：日志 / 延时 / 停止事件

标准积木：逻辑、循环、数学、文本、列表、变量、函数 全部可用。

## 安全说明

- 程序在**受限沙箱**中执行：仅暴露白名单 builtins（不含 `__import__`、`open`、`eval`、`exec` 等），并提供 `event`/`ctx`/`_blk` 三个对象。
- 每个程序有独立的**执行超时**（默认 30 秒），超时自动终止。
- 注意：`while True` 等 CPU 密集死循环无法被 asyncio 超时中断，请在程序中避免；使用积木"延时/循环"时注意次数。
- 请只允许可信人员使用本插件（程序拥有与机器人同等的操作能力，如发送消息、调用 AI、发起 HTTP 请求）。
